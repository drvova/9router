## Design Context

### Users
9Router primarily serves individual developers operating a local AI routing gateway beside terminal-based coding tools, while retaining responsive remote access for quick monitoring and administration. The dashboard should optimize fast inspection, debugging, provider management, quota awareness, and reliable recovery from routing failures. Core actions must work with mouse, keyboard, and touch across desktop and mobile browsers.

### Brand Personality
Practical, warm, and resilient. The interface should feel like a dependable developer utility: operationally dense without becoming austere, approachable without becoming playful, and calm under failure conditions. Its emotional goals are confidence, continuity, and control.

### Aesthetic Direction
Preserve the established dashboard language: warm coral accents, gently tinted neutral surfaces, compact utility-oriented layouts, rounded geometry, restrained elevation, Material Symbols, and semantic light/dark themes. Prefer the dashboard token system over the separate promotional landing-page treatment. Adapt interactions intentionally for small screens rather than merely shrinking desktop controls.

### Design Principles
1. Put high-frequency operational actions close to the data they affect and provide immediate, accessible feedback.
2. Preserve full functionality on mobile with 44px touch targets, responsive reflow, and no hover-only controls.
3. Keep developer workflows compact and legible on desktop while supporting keyboard navigation and visible focus.
4. Meet WCAG AA fundamentals for contrast, semantics, labels, focus behavior, and reduced motion.
5. Reuse semantic tokens and established shared components so light mode, dark mode, localization, and RTL remain consistent.
